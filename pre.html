How AlphaGo works
Board Game
Simulates millions of possible move sequences
Each move accounts for the opponent's optimal response
Deeper lookahead reveals traps humans miss

🌐
How Kairos works
Real World
LLM agents roleplay each decision-maker in the game
Each agent updates its strategy based on prior round outcomes
Multi-round simulation surfaces consequences invisible at step 1
Rules are fuzzy, state space is infinite — that's precisely the value
Depth
Multi-round iteration
Each round's output feeds the next, simulating path dependency and escalation spirals
Breadth
Monte Carlo sampling
Random perturbations injected; same starting point runs 500 times to map all viable paths
Transparency
Full decision audit trail

Architecture

Four steps make one full simulation run.
Repeat N times to get a distribution.

Step 01
Actor Modeling
Write a system prompt for each decision-maker: objective function, resource constraints, and non-negotiable red lines
LLM Prompt
Step 02
Multi-Round Interaction
Agents take turns outputting decisions; a referee agent updates world state and injects random events; repeat 8–12 rounds
Multi-Agent Loop
Step 03
Outcome Extraction
Structured extraction of each round's result: tension level / duration / key nodes that triggered escalation
JSON Output
Step 04
Monte Carlo Aggregation
Aggregate 500 runs to generate probability distributions, path clustering, and sensitivity analysis
Statistics

We've Built This Before

Prior work validates
the core mechanism.

POLYMARKET FORECASTING · CMU · 2025

We built a multi-agent forecasting system on 500 real-world prediction market questions.

The gain didn't come from more agents — it came from how information was allocated across them. Agents with overlapping evidence just herded. Agents with complementary evidence genuinely revised.

POLYGYM BENCHMARK · N = 500
SINGLE AGENT
71.6% accuracy
MULTI-AGENT
78.2% accuracy +6.6pp
Structure beats scale. Kairos is built on the same principle — each agent holds a distinct role, distinct constraints, distinct information.
